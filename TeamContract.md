# Meeting cadence for both team-only and advisor meetings
## Team-Only
Team only meetings. 
These meetings will be more 'work-time'.
Team memebrs shall sync up on each others status
Each memeber should come with a plan and complete work accordingly. 
These will happen on an as-needed basis and can be remote. 
## Advisor Meetings
Meetings held with the project adivsor will follow more of a schedule. 
1. These meetings should all be scheduled and start at a specific HH:MM Time
2. These meetings will start off with an update on the 'state of the project' 
3. Each Team member will say if they are on track, stuck, ahead, or have special news.
4. A plan will be formed in the meeting to determine if the current course of action needs to be altered. 
Every team member should always attend this meeting in person if possible. 

# Decision-making process and tiebreaker
If there is to be a debate between the two members, a disucssion with the advisor should be used to determine the reaction, unless the team memebers can resolve it faily intially.

# Conflict-resolution escalation plan
- In the event of a disagreement, team members will first attempt to resolve the issue internally through respectful communication and a review of the project objectives.
- If a resolution cannot be reached within 48 hours, the issue will be documented and elevated textually to the advisor for mediation. All memebers must agree with the final decision of the matter and react accordingly and remain professional.
